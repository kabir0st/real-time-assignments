Question: Consider the computeSomething function, which has a fixed-length execution
time slightly equal to 1 tick. Remove the code while(t==ticks);, compile the code, and
boot the RPi using the newly created kernel. 

What is the result and implication of removing the code while(t==ticks);? Elaborate on your
answer.

ANSWER:

Purpose of the while loop is it makes tasks wait until next tick occurs, making sure each task run for one tick duration.
Without it tasks would finish and be rescheduled too quickly.

So removing it breaks the intended scheduling behavior cause tasks won't maintain their intended periods (like 3,5,7),
CPU utilization calculations become invalid and Rate Monotonic scheduling assumptions are violated.
